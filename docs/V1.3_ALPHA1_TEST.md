# V1.3-alpha2 — plan de pruebas TCP + UDP + reglas

## 1. Arranque

- Instalar APK.
- Aceptar permiso VPN.
- Confirmar `ACTIVO` y `Red actual: Wi‑Fi` o `Datos móviles`.
- Confirmar que la app no se cierre en API 24.

## 2. TCP permitido

- Levantar `python -m http.server 8080 --bind 0.0.0.0` en el PC.
- Abrir `http://IP_DEL_PC:8080` desde Chrome.
- Confirmar `TCP SYN`, `TCP OPEN`, `ESTABLISHED`, `C2S_DATA`, `S2C_DATA`.
- Confirmar `uid` y `pkg` de Chrome.

## 3. TCP bloqueado por Wi‑Fi

- Activar Wi‑Fi para Chrome.
- Apagar Wi‑Fi de Chrome en REGLAS.
- Repetir conexión al PC.
- Esperado: `TCP BLOCKED`, sin `TCP OPEN` ni `CONNECTING`.

## 4. UDP permitido

- Usar un dominio no cacheado en Chrome o una app que produzca tráfico UDP.
- Esperado: `UDP FIRST_SEEN`, `resolver=/proc/net` en API 24–28, y `UDP S2C_DATA` si llega respuesta.

## 5. UDP bloqueado

- Apagar Móvil o Wi‑Fi para la app correspondiente según la red actual.
- Generar un datagrama UDP.
- Esperado: `UDP BLOCKED` y ningún socket UDP nuevo.

## 6. Cambio de red

- Wi‑Fi: app permitida.
- Móvil: app bloqueada.
- Cambiar Wi‑Fi → datos móviles.
- Esperado: `NETWORK = Datos móviles` y cierre de sesiones activas bloqueadas.

## 7. Sesiones

- Comprobar que los contadores TCP/UDP vuelven a cero después de detener la VPN.
- Confirmar recuperación normal de Internet después de apagar la VPN.
